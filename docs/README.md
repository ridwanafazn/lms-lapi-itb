Dokumentasi
===========

Kumpulan dokumen teknis proyek LMS PT LAPI ITB. README di akar proyek memuat
gambaran singkat untuk pembaca baru. Dokumen di folder ini masuk lebih dalam ke
topik tertentu.

| Dokumen | Isi |
|---|---|
| [DOMAIN.md](DOMAIN.md) | Entitas bisnis, aturan harga, masa berlaku akses, dan syarat kelulusan |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Lapisan aplikasi, alur permintaan, dan alur pembayaran |
| [ERD.md](ERD.md) | Diagram relasi data dan diagram C4 level satu sampai tiga |
| [ENVIRONMENT.md](ENVIRONMENT.md) | Cara menjalankan aplikasi, layanan pendukung, dan akun demo |
| [TESTING.md](TESTING.md) | Cara menjalankan pengujian dan pengamanan basis data uji |
| [CONVENTIONS.md](CONVENTIONS.md) | Gaya kode dan penamaan |
| [WORKFLOW.md](WORKFLOW.md) | Alur kerja harian dan definisi selesai |
| [DECISIONS.md](DECISIONS.md) | Catatan keputusan arsitektur |
| [ROADMAP.md](ROADMAP.md) | Rencana kerja per fase dan statusnya |
| [KNOWN_ISSUES.md](KNOWN_ISSUES.md) | Temuan yang masih terbuka dan utang teknis |
| [PHASE2.md](PHASE2.md) | Rekap fitur operasional dan aturan bisnisnya |
| [PHASE3.md](PHASE3.md) | Rekap perbaikan performa dan pengalaman pengguna |
| [screenshots](screenshots/README.md) | Daftar tangkapan layar yang disarankan untuk portofolio |

Urutan baca yang disarankan untuk pengembang baru adalah DOMAIN, ARCHITECTURE,
ERD, ENVIRONMENT, lalu TESTING.
